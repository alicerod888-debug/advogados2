# Site do escritório

Next.js 14 + React + TypeScript + Tailwind + Framer Motion + Lucide.

1. `npm install` e `npm run dev` (http://localhost:3000)
2. Edite **src/lib/site.ts** com nome, WhatsApp (só dígitos, ex.: 5574999999999), telefone, e-mail, endereço, Instagram, advogados e depoimentos reais.
3. Publicar: suba no GitHub e importe na Vercel (sem configuração extra). Cloudflare Pages exige o adaptador `@cloudflare/next-on-pages`.
4. Antes de publicar: troque `url` em site.ts, adicione fotos em `public/` e uma imagem Open Graph (`src/app/opengraph-image.png`).
